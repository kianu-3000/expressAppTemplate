Title:
    Church Tithes System -> On Hold

Description:
    The main goal of this system is to pay tithes every sunday to a church bank account.
    where members can see each other who paid and who did not. "I can see no possible problems
    in this type of system" - (sarcastically speaking)

Core Features:
    -> register phone number to be able to receive otp code for login and initial registration
        : upon registration phone number is saved in data base.
        : this will enable phone number otp login.
    -> landing page
        : members can view list of members.
        : be able to click them and see more details.
        : more details - includes monthly tithe donation information.
    -> Donation Tithes
        : members can send donation to church bank account
        : members' details will be updated
